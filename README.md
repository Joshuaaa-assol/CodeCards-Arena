CodeCards Arena

Problem
Many programming students struggle to find an engaging and interactive way to practice programming concepts. Traditional learning methods may lack competitive elements, progress tracking, and motivation. Students also need a platform where they can test their knowledge across different programming languages and difficulty levels.
Target Users
- Programming students
- Beginner and intermediate programmers
- Coding enthusiasts
- Competitive programming learners
- 
Solution
CodeCards Arena provides an interactive coding quiz platform where users can practice programming questions, challenge themselves through different game modes, track their performance, and compete with other players through an Elo-based ranking and leaderboard system.
Main Feature
- Programming Quizzes – Provides programming questions retrieved through QuizAPI.
- Multiple Programming Languages – Supports Java, Python, JavaScript, C++, and other programming languages.
- Game Modes – Offers Blitz, Rapid, and Classic modes.
- Practice Mode – Allows users to practice without affecting their competitive ratings.
- Elo Ranking System – Adjusts player ratings based on quiz performance.
- Global Leaderboard – Displays player rankings based on Elo ratings.
- Statistics and Achievements – Tracks user performance and accomplishments.
- User Accounts – Allows users to register, log in, and save their progress.
- 
Pages
- Homepage: The main landing page that introduces CodeCards Arena. It presents the platform's purpose, highlights its features, and provides access to login and registration.

- Dashboard: Displays the user's overall Elo rating, current rank, practice streak, quiz statistics, recent activity, and progress.

- Play Arena: The main competitive quiz section where users can choose a game mode and configure their quiz session.

- Quiz Configuration: Allows users to select their preferred programming language, topic, difficulty level, and number of questions before starting a quiz.

- Quiz Game: Displays programming questions with multiple-choice answers, timers depending on the selected game mode, question progress, and answer feedback.

- Practice Mode: Allows users to answer programming questions at their own pace without affecting their competitive Elo rating.

- Leaderboard: Shows the rankings of participants based on their Elo ratings, including their names, scores, and positions.

- Statistics: Displays the user's performance information, including accuracy, correct and incorrect answers, answering time, and Elo progression.

- Profile: Shows the user's personal information, profile picture, nickname, rank, and overall Elo rating. It also allows profile customization.

- Achievements: Displays unlocked and locked achievements based on the user's progress and accomplishments.

- Settings: Allows users to customize their preferences, such as theme, default programming language, and animation settings.

- Cart or Subscription Page: Not applicable. CodeCards Arena does not currently offer shopping cart or subscription functionality.
