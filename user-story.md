User Stories – CodeCards Arena
Feature: User Registration and Login
US1: As a new user, I want to create an account, so that I can save my coding progress and access my personal profile.

US2: As a registered user, I want to log in to my account, so that I can access my saved statistics and achievements.

US3: As a guest user, I want to continue without creating an account, so that I can explore and play quizzes without registering.

Feature: Coding Quiz and Practice
US1: As a coding student, I want to select a programming language and topic, so that I can practice questions based on my preferred programming subject.

US2: As a quiz participant, I want to choose a game mode and difficulty level, so that I can challenge myself according to my skills.

US3: As a coding student, I want to answer programming questions and receive feedback, so that I can evaluate and improve my programming knowledge.

Feature: Leaderboard and Performance Tracking
US1: As a registered user, I want to view the global leaderboard, so that I can compare my Elo rating with other participants.

US2: As a coding participant, I want to view my statistics and quiz history, so that I can monitor my performance and progress.

US3: As a coding participant, I want to earn achievements and improve my rank, so that I stay motivated to continue practicing and competing.
